What the AAU Plugin Does

🎯 Core Achievement Unlocking
🚀
Fully Automatic Unlocker
One-click auto-unlock for entire games. The plugin handles timing, progress tracking, verification and error recovery automatically — just press Start and let it run.
🎯
Manual Single Unlock
Unlock any individual achievement by ID. Perfect for picking off specific achievements you are missing.
🧠
Smart Unlock Order
Enter a reference gamertag and the plugin pulls their achievement data directly from Xbox Live, generating a perfectly timed unlock order with original timestamps preserved.
⏱️
Custom Timing Control
Choose original timing (replicates the reference player's unlock schedule) or set custom delays in hours and minutes for faster or slower unlocking.
🎮 Game Queue & Batch Processing
📋
Multi-Game Queue
Queue up multiple games and let the plugin unlock them all sequentially — automatically moving to the next game when one finishes, with configurable cooldown between games.
📥
Queue Import
Paste a list of title IDs and gamertags to bulk-add games to the queue instantly.
🧩
Stack Suggestions
Automatically detects cross-platform versions of the same game (e.g. Xbox One vs. Series X|S) and suggests adding them all to the queue at once.
🕘
Gamertag History
Remembers your last 10 used gamertags with auto-complete, so you don't have to re-type them.

📡
RTA WebSocket Monitoring
Connects to Xbox Live's real-time achievement event stream via WebSocket, providing instant feedback when achievements unlock — no polling delays.
🛡️
Multi-Layer Fallback
If an unlock fails, the plugin automatically retries with alternate strategies: string replacement, main folder data fallback and title-based nudge. Achievements that are 100% complete but still locked get a special force-unlock attempt.
